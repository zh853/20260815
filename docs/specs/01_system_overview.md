# 01. 系統總覽與三位一體閉環架構規格 (System Overview Specification)

## 1.1 系統定位與目標
**ArchSystems 建築師事務所三位一體整合系統 (ERP System)** 專為中大型建築師事務所設計，旨在解決傳統事務所中「外勤打卡無法追蹤」、「專案工時成本無法算帳」、「結案獎金發放不公」與「勞基法薪資計算複雜」等痛點。

---

## 1.2 三位一體核心閉環業務邏輯
系統以數據流為核心，建立以下四大業務閉環：

```
[ 1. GPS 差勤打卡與外勤 ] ──> [ 2. 專案工時填報與階段成本分攤 ]
            │                                    │
            ▼                                    ▼
[ 4. 勞基法二分法薪資與車資 ] <── [ 3. 360 績效與專案結案盈餘獎金 ]
```

1. **差勤與出勤流 (Attendance Flow)**：
   - GPS 地理圍欄 (200m) + WiFi BSSID 雙重驗證打卡。
   - 公出都發局/建管處跑照、業主會議自動判定「公出免簽退」。
   - 請假可選擇直接扣抵「加班積休時數池 (Comp-time Pool)」。
2. **工時與成本流 (Timesheet & Labor Cost Flow)**：
   - 區分專案階段工項 (SD 方案/Permit 送審/CD 施工圖/Supervision 監造)。
   - 按員工「小時成本率 (Hourly Cost Rate)」即時歸攤至專案，計算專案盈餘與預算警示。
3. **績效與盈餘流 (Performance & Profit Sharing Flow)**：
   - 360 度四維權重考核 (品質 40%/進度 30%/協作 15%/創新 15%)。
   - 專案結案時，提撥合規盈餘獎金池，依工時貢獻度與 PM 權重係數自動分派。
4. **薪資與合規流 (Payroll Compliance Flow)**：
   - 採「固定薪」與「變動薪」二分法展示。
   - 自動計算一例一休加班費倍率 (1.34 / 1.67 / 2.67)、勞健保同仁自負額與雇主負擔、交通出差車資與里程補貼。

## 1.3 角色與權限矩陣 (RBAC Matrix)

| 角色名稱 | 權限代碼 | 主要職責與可存取面板 |
| :--- | :--- | :--- |
| **基層繪圖員 / 助理** | `ROLE_STAFF` | 手機/桌面 GPS 打卡、週/日工時填報、查看個人薪資單與請假扣抵。 |
| **專案經理 / 建築師** | `ROLE_PM` | 專案工時審核、專案階段進度維護、專案結案盈餘獎金分配建議。 |
| **人事與財務主管** | `ROLE_HR_FIN` | 全所差勤審核、勞基法薪資計算與發放、交通車資補貼審核、薪資單產出。 |
| **主持建築師** | `ROLE_DIRECTOR` | 全所經營儀表板 (KPI/利潤率/產值)、績效終審簽核、結案獎金撥付批准。 |
