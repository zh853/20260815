## 📌 計劃檔案命名規範 (Naming Convention)
- 所有計畫文件統一儲存於 `docs/plan/` 目錄。
- 檔案命名格式：`plan-[編號]-[短主題功能].md` (例如 `plan-01-bim-ai-auto-drawing-integration.md`)。
- 每份計畫需包含：**背景動機、功能範圍、技術可行性分析、資料結構擴充、實作時程規劃**。
